# 一维数组（array）

> 返回 [教程目录](README.md) · 下一章 [数组批量运算](array-bulk.md)

## 什么时候用

一段连续内存的随机读取和写入：计数器数组、缓冲区、查找表、需要在表达式里频繁 `buf[i]` 的场景。

数组不维护长度以外的状态，没有隐藏变量；长度 `size` 是编译期常量，可直接用 `len(buf)` 读取。

## 声明卡

```text
array <name> <memory> <base> <size>
```

| 字段 | 说明 |
| --- | --- |
| `name` | 表达式里使用的数组名，例如 `buf` |
| `memory` | 承载数据的内存块变量名，如 `cell1` / `bank1` |
| `base` | 起始物理地址，非负整数字面量 |
| `size` | 元素个数，正整数 |

示例：`array buf cell1 0 8` 表示 `buf[0]..buf[7]` 对应 `cell1` 的地址 `0..7`。

声明卡只是编译期元数据，不产出任何 mlog 行。

## 表达式写法

| 写法 | 含义 | 结果 |
| --- | --- | --- |
| `buf[i]` | 读取下标 i | 越界返回 NaN |
| `buf[i] = expr` | 写入下标 i | 越界不写入 |
| `len(buf)` | 编译期长度 | 常量 `size` |

`i` 可以是任意表达式；下标是整数字面量时在编译期折叠，是变量时在运行时计算地址。

## 转译示例

下面每段示例都按 Sugar 源码形式书写（也就是声明卡与 Expr 卡里的内容）。这段文本可以直接粘进处理器的代码框：声明行会导入成卡片，`x = buf[3]` 这类赋值行会导入成 Expr 卡，而不是变成一张空的 `noop` 卡。

### 字面量下标：直接折叠

```text
array buf cell1 0 8
x = buf[3]
```

产物：

```text
read x cell1 3
```

### 变量下标：地址 = base + i

```text
array buf cell1 10 8
x = buf[i]
```

产物：

```text
op add _0 10 i
read x cell1 _0
```

如果 `base == 0`，地址就是 `i` 本身，不需要额外加法：

```text
read x cell1 i
```

### 下标写入

```text
array buf cell1 10 8
buf[i] = 5
```

产物：

```text
op add _0 10 i
write 5 cell1 _0
```

### 长度

```text
array buf cell1 0 8
x = len(buf)
```

`len(buf)` 在编译期折叠成 `8`；因为这是表达式语句，产物是：

```text
op add x 8 0
```

在条件里也会直接使用字面量，例如 `if begin expr "len(buf) > 2"` 会编译出 `op greaterThan ... 8 2`。

## 复杂度

| 操作 | 复杂度 |
| --- | --- |
| `buf[i]` 读 | O(1)，单条 `read` |
| `buf[i] = v` 写 | O(1)，单条 `write` |
| `len(buf)` | O(1)，编译期常量 |

## 使用须知

- **越界语义**：字面量下标越界（如 size 8 写 `buf[8]`）是编译错误；变量下标越界在 strip 模式下不额外检查，运行时越界 `read` 返回 NaN，越界 `write` 是空操作。开启调试断言构建时，非常量下标会在读写前插入 `assertBounds`。
- **base/size 必须是整数字面量**；运行时不支持动态改变数组长度。
- **容量检查**：`cellN` 容量 64、`bankN` / `worldN` 容量 512；`base + size` 超容量编译期报错。其它名字跳过检查。
- **重名**：数组名不能与其它数组、矩阵或用户函数重名；与其它数据结构的重名/区间重叠属于跨模块已知限制，需要自己避免。
- **内存只存数字**：当前内存槽读写按数字处理；对象值（单位、建筑等）请先用 `sensor` / `op` 转成数字再存，或参考 [架构总览](../architecture.md) 的「内存对象存储」说明。
- **未声明时的退化**：如果表达式里写了 `x[i]` 但 `x` 不是已声明数组，在数组注册表为空的场景会退化成普通 `read x i`（这是原版风格的裸 read）；一旦程序里有任何数组声明，未声明的 `x[i]` 会报「未知数组」。
- **与 list/bitset/chain 的下标糖冲突时数组优先**：如果同名变量同时声明为数组和 list 等，`x[i]` 按数组解释。不要依赖跨模块重名。
